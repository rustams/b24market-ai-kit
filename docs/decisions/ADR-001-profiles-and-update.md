# ADR-001: общий исходник и разные каналы поставки

Дата: 15.10.2026. Статус: реализовано локально, нативная приёмка открыта.

Вместо отдельного форка local/marketplace выбран общий module/ и явные команды упаковки. Генератор создаёт независимый проект с собственными знаниями, скиллами и проверенными upstream security materials. Runtime Composer зависимостей нет. Storage опционален; базовый сценарий не создаёт бизнес-таблиц.

Marketplace updater выполняется до нового class API, поэтому lifecycle support возвращает closures и включается из обновления. Полное дерево собственного активного компонента является необходимым support payload delta; остальные неизменённые runtime файлы исключаются. Local deployment генерирует согласованные активные копии из commit; CLI обновляет manifest и миграции без DoInstall.

Операции файлов ограничены фиксированным owner prefix, preflight/symlink/hash, проверкой копии и компенсацией при исключении. Питание, конкурирующая доставка и глобальный SiteUpdate не объявляются атомарными. Пользовательские кастомизации вызывают остановку. Автоматическое удаление старых файлов заблокировано до документированного механизма и отдельного теста.

Upstream skills импортированы по MIT на точный SHA, копируются генератором offline. Команда обновления проверяет SHA/license/symlinks/local hashes и не исполняет импорт. Silent latest updates не используются: агентные инструкции и tooling требуют review до исполнения.

Открыты: native Loader/ORM/installer/updater, cabinet acceptance macOS filename, лицензирование/модерация, role UI и OS/cluster/FPM. Official sources приведены в sources.json; источники Radar не копировались из-за отсутствия явной лицензии на проект.
