# Архитектура и API

Проектное решение: один канонический каталог `module/` и два канала упаковки. PHP/D7 сервисы находятся в `lib/`, компонент — в `install/components`, настройки — `options.php`. Namespace зарегистрирован через Loader, файлы классов строчные. Установщик наследует CModule; метаданные и версия отделены, пользовательские тексты локализуются через Loc.

Это расширение коробочного продукта. REST документация относится к интеграциям и приложениям; для in-process ORM и установки нужен PHP/D7 контракт. Не переводите доступ к локальной БД в webhook автоматически. Для каждого неизвестного метода зафиксируйте official URL, версию и проверенный вызов.

Исходники модуля могут быть установлены штатно в local или bitrix. Не определяйте путь жёстко: для lookup используйте `Loader::getLocal('modules/<id>/...')`, document root — `Application::getDocumentRoot()`, внутри модуля — `__DIR__`. Компонент подключает модуль по ID. Не храните две установленные копии: приоритет local может скрыть Marketplace обновление.

Базовый пример не обслуживает ресурсы через прямые HTTP URL внутри modules. Если добавляете JS/CSS, установите принадлежащие модулю ресурсы в соответствующий публичный каталог и зарегистрируйте Bitrix UI extension; URL ресурса относится к активной копии. Проверьте HTTP/Network на реальном портале. Возможность include PHP не доказывает доступность HTTP URL.

Сервис Demo хранит короткое несекретное приветствие в Option; кэширует только два представления на identity/right/site/language с TTL 60. При сохранении и удалении чистится только его каталог кэша. Опциональное хранилище имеет собственную MySQL таблицу и точный owner predicate в ORM; не обещает поддержку PostgreSQL.

Добавляйте событие, агента, очередь или таблицу только после сценария, владельца данных, retention и прав. Для фонового процесса требуются остановка, идемпотентность, блокировка конкуренции, bounded batch, retry limit и cleanup. Никакой автоматической регистрации CRM прав или доступа ко всем объектам.

ADR фиксирует альтернативу, причину, последствия и незавершённые проверки. Разрешение на локальный код не является разрешением на установку или production.
